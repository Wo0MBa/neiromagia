Промт генератора целиком

Создай генератор
Создай генератор. Действуй как Senior Frontend Developer и Game Designer. Напиши интерактивную обучающую 2D-игру платформер на чистом HTML, CSS и JavaScript (Canvas API) в одном файле.
Тема: Правило русского языка «Н и НН в суффиксах» для старшеклассников

1. Стартовое меню (UI/UX):
Меню должно быть поверх игры и кнопкой «Начать игру».
Добавь инпуты <input type="file"> для загрузки кастомного фона (jpg/png) и кастомного героя (png с прозрачностью) через FileReader.
Добавь ползунок <input type="range"> для изменения размера героя (от 40px до 200px, по умолчанию 90px). Хитбокс (ширина и высота) героя должен строго соответствовать этому значению.

2. Механика игры и физика (Без багов):
Управление: Стрелки влево/вправо (или A/D) для бега, Стрелка вверх/Пробел/W для прыжка.
Генерация мира: Платформы генерируются бесконечно и движутся влево (эффект бега героя вправо). Расстояние между платформами (gaps) должно быть строго проходимым! Настрой гравитацию (gravity), силу прыжка (jumpPower) и скорость (speed) так, чтобы герой легко долетал до следующей платформы без технических «недолетов».
Коллизии: Игрок должен приземляться строго на верхнюю грань платформы. Исключи баги проваливания сквозь текстуры. Ограничь выход героя за левый и правый края экрана.
Полноэкранный режим: Добавь кнопку «На весь экран», которая использует нативный Fullscreen API (requestFullscreen). Canvas должен автоматически ресайзиться под размер окна (window.innerWidth/innerHeight).

3. Обучающая часть (Сбор монет):
На некоторых платформах генерируются золотые монетки. При касании монетки (проверка дистанции между центрами) игра ставится на паузу.
Появляется модальное HTML-окно. В нем выводится случайное слово из базы (например, «Стекля__ый») и две кнопки: «Н» и «НН».
Верный ответ: Модальное окно закрывается, выводится зеленая надпись «Верно!», счет увеличивается на 10, скорость игры чуть возрастает, игра продолжается.
Неверный ответ: Выводится красная надпись с правильным написанием слова, игра продолжается без начисления очков.

4. Технические требования:
Все стили и скрипты должны быть внутри одного HTML-файла. Используй requestAnimationFrame для игрового цикла.
Если герой падает мимо платформы за нижний край экрана (y > canvas.height) — игра окончена (alert с итоговым счетом) и возвращение в главное меню.
Сделай красивый современный CSS-дизайн модальных окон и кнопок, добавь пиратские шрифты (например, Russo One из Google Fonts).
